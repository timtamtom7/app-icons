# AI Image Generator Prompts — macOS App Icons (iOS 26 Style)

Copy each prompt and paste into DALL-E / Midjourney / Ideogram / Flux.

## Style Reference
Think of: MacPaw, Setapp, Linear, Raycast, Figma — premium macOS app icons. Dark backgrounds, vibrant glass-like shapes, subtle depth, no clutter.

## Tips
- **DALL-E:** Paste as-is, request 1024x1024 PNG
- **Midjourney:** Paste as prompt, add `--style raw --s 250 --v 6 --ar 1:1`
- **Ideogram:** Paste as prompt, select "General" style, 1:1 ratio
- **Flux:** Paste as prompt, add "photorealistic glass morphism app icon"

## Reference Inspiration
- **Linear** — dark bg, vibrant purple/gradient shapes, minimal
- **Raycast** — frosted glass, clean geometry, dark mode
- **MacPaw apps** — warm, approachable, premium feel
- **Setapp icons** — all dark backgrounds, colored accents, frosted glass
- **Apple's macOS icons** — SF Symbol-based, depth and blur

Use these as your visual north star. Each icon should be instantly recognizable at 64x64 and beautiful at 512x512.
